AI Usage Policy
===============

The restic project allows the responsible usage of AI tools based on the following guidelines:

- **Disclose AI usage**: Disclose usage of AI tools in issues and pull requests. Name the tools and
  what they were used for.
- **Responsibility**: Commits must neither include a commit trailer for the AI tool nor list it as a
  co-author. You are fully responsible for your contribution.
- **Mandatory human oversight**: You have to fully review, understand and clean up the AI
  output before creating pull requests or posting it anywhere. The first person to read the AI
  output is you and **not** the maintainers or other contributors.
- **Communication with humans**: We want to communicate with humans, not AI tools. While you can
  use help in drafting messages, you remain responsible for the content. Keep text written by AI
  tools reasonably compact, but make sure to still include important details and context.
